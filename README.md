## 🌟 What is Lassi AI?

**Lassi AI** is a friendly, bilingual AI assistant that speaks your language — **Hindi, English, and Hinglish**. Designed for users who think in one language and type in another, Lassi bridges the gap with natural, warm, desi-flavored conversations.

Whether you want to know the time, open a website, or just say *"Kaise ho?"* — Lassi is always ready. ●

---

## ✨ Features

| Feature | Description |
|---|---|
| 💬 **Text Mode** | Chat naturally in Hindi, English, or Hinglish |
| 🎙️ **Voice Mode** | Speak to Lassi using your microphone (Chrome/Edge) |
| 👋 **Greetings** | Personalized Hinglish greetings and responses |
| ⏰ **Time & Date** | Ask for current time or today's date instantly |
| 🌐 **Open Websites** | Launch YouTube, Google, and more by just asking |
| 🏷️ **Remembers You** | Lassi remembers your name during the session |
| 🤝 **Hinglish Replies** | Responses that feel natural to desi users |
| ⚡ **Quick Commands** | One-tap shortcuts for common actions |

---

## 🎯 Quick Commands

```
👋  "Hello" / "Namaste"     →  Warm greeting from Lassi
⏰  "Time kya hai?"          →  Current time
📅  "Aaj ki date?"           →  Today's date
▶️  "YouTube kholo"          →  Opens YouTube
🔍  "Google open karo"       →  Opens Google
😊  "Kaise ho?"              →  A friendly chat response
🏷️  "My name is [name]"      →  Lassi remembers you!
```

## 🚀 Getting Started

### Prerequisites

- A modern browser (**Chrome** or **Edge** recommended for Voice mode)
- No installation required — it's fully web-based!

### Run Locally

```bash
# 1. Clone the repository
git clone https://github.com/your-username/lassi-ai.git

# 2. Navigate into the project
cd lassi-ai

# 3. Open in browser
open index.html
# or serve with a local server:
npx serve .
```

### Deploy to Vercel

```bash
# Install Vercel CLI
npm i -g vercel

# Deploy
vercel
```

> 🔗 Live at: **[https://lassiai.vercel.app](https://lassiai.vercel.app)**
